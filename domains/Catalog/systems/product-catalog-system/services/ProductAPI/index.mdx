## Overview

The **Product API** is the front door to the Product Catalog System. It validates incoming commands, persists product data to the [[container|product-database]], and publishes product change events to the rest of the business.

For product **creates** and **deletes**, every change is recorded to the outbox so the [[service|product-search-publisher]] can relay it reliably to Kafka. For product **updates**, the API publishes the [[event|product-updated]] event directly to Kafka from the request path.

### Responsibilities

| Area | Description |
|------|-------------|
| Command handling | Validates and applies [[command\|create-product]], [[command\|update-product]] and [[command\|delete-product]]. |
| Reads | Serves [[query\|get-product]] directly from the product database. |
| Change capture (creates/deletes) | Records product creates and deletes to the outbox in the [[container\|product-database]] for the [[service\|product-search-publisher]] to publish. |
| Direct publishing (updates) | Publishes [[event\|product-updated]] directly to Kafka when a product is updated, bypassing the outbox. |
| Persistence | Reads from and writes to the [[container\|product-database]] (system of record). |
