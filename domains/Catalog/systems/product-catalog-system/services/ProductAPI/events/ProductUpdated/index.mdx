## Overview

`ProductUpdated` is published when an existing product's data changes in the catalog. It is currently published directly by the [[service|product-api]] from the `updateProduct` request handler, which sends the event straight to Kafka without going through the transactional outbox. The [[system|search-system]] consumes this event to re-index the product so search results stay accurate.
